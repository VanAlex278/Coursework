# Приложение для анализа банковских операций.

## Описание:

Приложение анализирует банковские операции из Excel-файла, генерирует JSON-данные для веб-страниц, формирует Excel-отчеты, а также предоставлять другие сервисы.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/VanAlex278/Coursework
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

Имеются следующие функций:

- main_page - формирует JSON-данные для главной страницы.
- get_greeting - формирует приветствие.
- load_transactions - загружае данные об транзакциях из Excel-файла.
- get_currency_rates - получает курсы валют ЦБ РФ.
- get_stock_prices - получяет чены на акции.

## Тестирование:

Все функции проекта протестированны с помощю pytest.
